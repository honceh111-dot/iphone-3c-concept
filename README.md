# iPhone 3C Concept Gallery

A bilingual, responsive static concept website covering headphones, chargers, portable power, and connection accessories.

This is an unofficial concept gallery, not an Apple website. iPhone is a trademark of Apple Inc. All accessory designs are fictional and images are AI-generated. Products are not for sale.

## Preview

Serve this folder with any static HTTP server and open `index.html`. All asset paths are relative and compatible with GitHub Pages repository hosting.

## Pages and interactions

- Homepage: collection, category filters, design philosophy.
- Four product detail pages: `headphones.html`, `charger.html`, `powerbank.html`, `cable.html`.
- About page: design philosophy and expandable FAQ.
- Chinese / English switch, persisted locally; responsive navigation; accessible product tabs.

## Editing

Product content lives in `product-data.js`. Shared page copy and markup live in `site.js`. Styling lives in `style.css`. Final image assets live in `assets/`.

No payment, backend, tracking, inventory, or external font dependency is included.
